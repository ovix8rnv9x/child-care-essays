# 【医学知识】地震创伤救治原则

> 更新时间：2026-09-11 (UTC+8)

8月3日16时30分在云南省昭通市鲁甸县(北纬27.1度，东经103.3度)发生6.5级地震，震源深度12千米，震区的灾情时刻牵动着全国人民的心，北京大学人民医院的4位专家也正在昭通全力以赴地抢救着更多伤员，与时间赛跑，与死神竞速！

地震常造成严重的骨骼创伤，比如：开放性骨折、脊柱损伤、挤压综合征等。救出伤员后，应第一时间进行医疗急救：

1. **确保呼吸道通畅：**伤员因气道阻塞而发生呼吸不畅或窒息时应采取措施清除气道阻塞物，必要时行环甲膜切开或气道造口等紧急措施以确保呼吸道通畅。

2. **心跳呼吸的复苏：**在严重创伤时常发生心脏呼吸同时或相继的骤停，一经出现，应立即行心脏按压和人工呼吸，切忌反复检查，贻误抢救时机。

3. **快速止血包扎与固定：**大出血是伤后早期死亡的主要原因之一，此时应采取及时有效的止血措施，挽救患者生命。对于骨与关节损伤的病人，尽早作外固定，不仅可以减轻疼痛，而且更重要的是可防止骨折断端在搬运中刺伤神经和血管。

4. **搬运：**经上述处理后，应尽快将伤员送至远离震区的安全地带。对于脊柱骨折的伤者,在搬动过程中切忌采用横抱、“一人抬胳膊一人抬脚”等方式,因为这可导致骨折的脊柱对脊髓造成损伤,继而致使伤者截瘫。正确的做法应该是使用硬质担架或木板搬运,疑有颈椎骨折时应立即用颈托固定。操作要小心，严防骨折错位，加重脊髓和（或）脊神经损伤。
