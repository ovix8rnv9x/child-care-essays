# 驻马店中心医院生殖科哪个医生助孕技术好？

驻马店中心医院生殖科的李智会、王慧、耿玲、刘慧源、周爱青都是该院特别厉害的助孕医生，其都从事妇产科、男科、泌尿外科等辅助生殖技术相关行业多年的老医生，拥有非常丰富的临床诊治及助孕经验。据了解驻马店中心医院现已开展了夫精人工授精技术，找这几位医生做该手术，助孕成功率最高可达20%左右，算是驻马店试管婴儿医院中成功率较高的。

驻马店市中心医院生殖医学科是该院新兴特色学科，2017年2月获批筹建夫精人工授精（AIH）技术，2019年1月28日获批试运行AIH技术，目前是驻马店市唯一一家经授权正式开展人类辅助生殖技术的医疗机构。目前科室医、技、护人员20余名，其中高级职称4人，中级职称6人。其中助孕技术较好的医生有：

- 1. 周爱青（主任医师）：擅长妇科肿瘤及不孕不育诊治、妇科疑难杂症等助孕；
- 2. 李智会（主治医师）：擅长生殖内分泌疾病如排卵障碍、复发性流产、反复植入失败等；
- 3. 王慧（主治医师）：擅长不孕不育症及妇科内分泌疾病，如原发及继发不孕症、多囊卵巢综合征等等；
- 4. 耿玲（主治医师）：擅长不孕不育、复发性流产、多囊卵巢、月经不调、女性更年期等疾病治疗；
- 5. 刘慧源（主治医师）：对于男女常见不孕症、复发性流产、多囊卵巢综合症、妇科内分泌等疾病的诊治具有独特见解。
以上就是驻马店中心医院生殖科助孕技术厉害的医生，这些医生目前都在该院有排班，但并不固定，有需要去该院就诊的患者，可以事先在该院微信公众号预约挂号，以免耽误助孕治疗时间。
